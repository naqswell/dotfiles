# Правила для Codex CLI на этом Mac

Глобальные правила поведения агента. Проектные правила добавляются иерархически
(`~/mts/AGENTS.md` и `<project>/AGENTS.md`). У Claude Code те же правила лежат
в `~/.claude/CLAUDE.md` — при правках держать оба файла согласованными.

- Отвечать по-русски.
- Не добавлять `Co-Authored-By`, `Claude-Session:` и `Generated with Claude` в коммиты
  и описания MR/PR.
- Не коммитить и не пушить самостоятельно — только по явной просьбе.
- Показывать в ответе точную запускаемую команду, если она меняет состояние
  (git, gradle, launchctl, установка/удаление).
- После коммита выводить отдельной строкой готовую к вставке команду
  `cd '<корень репозитория>' && git push <remote> <branch>` — путь в одинарных кавычках;
  remote брать из `git config branch.<branch>.remote`, иначе `origin`. Сам push не выполнять.
- Комментарий в коде пишем, только если без него читатель ошибётся.
- Если пользователь не отвечает, продолжать разумными дефолтами; спорные развилки называть
  в отчёте, а не блокироваться на них.
